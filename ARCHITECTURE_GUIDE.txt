TypeScript & Angular Coding Standards7.1 TypeScript Compiler Settings (tsconfig.json)```json{  "strict": true,  "noImplicitOverride": true,  "noPropertyAccessFromIndexSignature": true,  "noImplicitReturns": true,  "noFallthroughCasesInSwitch": true,  "target": "ES2022",  "module": "ES2022",  "moduleResolution": "bundler"}```> **RULE:** `strict: true` is non-negotiable. Never use `any` — use proper types or generics.7.2 Angular Compiler Settings```json{  "strictInjectionParameters": true,  "strictInputAccessModifiers": true,  "strictTemplates": true}```7.3 Import OrderAngular core (`@angular/core`, `@angular/common`, etc.)Angular Material (`@angular/material/*`)Third-party libraries (`rxjs`, `@ngneat/query`, etc.)Path alias imports (`app/*`, `shared/*`, `core/*`, `environment/*`)Relative imports (only within the same feature)7.4 Change Detection — Always OnPush```typescript@Component({  changeDetection: ChangeDetectionStrategy.OnPush,  // ...})```7.5 Dependency Injection — Always inject()```typescript// CORRECTexport class MyComponent {  private readonly myService = inject(MyService);}// WRONG — never use constructor injectionexport class MyComponent {  constructor(private myService: MyService) {}}```7.6 Template Syntax — Modern Control Flow```html<!-- CORRECT — Modern control flow -->@if (isLoading()) {  <mat-spinner />}@for (item of items(); track item.id) {  <div>{{ item.name }}</div>}@switch (status()) {  @case ('active') { <span>Active</span> }  @case ('inactive') { <span>Inactive</span> }  @default { <span>Unknown</span> }}<!-- WRONG — Legacy structural directives --><div *ngIf="isLoading">...</div><div *ngFor="let item of items">...</div>```---8. Component Anatomy8.1 Component File Structure (always 4 files)```<component-name>/├── <component-name>.component.ts├── <component-name>.component.html├── <component-name>.component.scss└── <component-name>.component.spec.ts```8.2 Component TypeScript Pattern```typescriptimport {  ChangeDetectionStrategy, Component, computed,  inject, input, model, output, signal} from '@angular/core';@Component({  selector: 'app-<component-name>',  templateUrl: './<component-name>.component.html',  styleUrls: ['./<component-name>.component.scss'],  standalone: true,  changeDetection: ChangeDetectionStrategy.OnPush,  imports: [    // List only what this component uses  ],})export class <ComponentName>Component {  // Inputs (Signal API)  public readonly myInput = input<string>('');  public readonly requiredInput = input.required<string>();  public readonly twoWayModel = model<boolean>(false);  // Outputs (Signal API)  public readonly myEvent = output<string>();  // Services (inject, not constructor)  private readonly myService = inject(MyService);  // Local State (signals)  private readonly _count = signal(0);  // Computed values  public readonly displayValue = computed(() => `Count: ${this._count()}`);  // Public methods  public onActionClicked(): void {    this._count.update(c => c + 1);    this.myEvent.emit(this.displayValue());  }}```8.3 Inputs & Outputs — Signal API (MANDATORY)```typescript// CORRECT — Signal-based (new API)public readonly title = input<string>('Default');public readonly items = input.required<Item[]>();public readonly value = model<number>(0);public readonly selected = output<Item>();// WRONG — Decorator-based (legacy, do not use)@Input() title: string = 'Default';@Output() selected = new EventEmitter<Item>();```---9. Service Pattern (BaseApiService)9.1 Every HTTP service MUST extend BaseApiService```typescriptimport { Injectable, inject } from '@angular/core';import { HttpClient } from '@angular/common/http';import { BaseApiService } from 'shared/services/base-api.service';import { ApiUrlService } from 'core/services/api.url.service';import { MyEntity, MyEntityDetail, MyEntityCreate } from 'shared/types/my-entity';@Injectable({ providedIn: 'root' })export class MyEntityService extends BaseApiService<  MyEntity[],       // T  — GET list response type  MyEntityDetail,   // T1 — GET by ID response type  MyEntityCreate    // T2 — POST / PUT body & response type> {  constructor(http: HttpClient) {    super(http, inject(ApiUrlService).apiUrl);  }  public override controllerName(): string {    return 'my-entities';  }}```9.2 BaseApiService Available MethodsMethod	HTTP	URL`get(options?)`	GET	`/{controller}?params``getById(id)`	GET	`/{controller}/{id}``insert(entity)`	POST	`/{controller}``update(id, entity)`	PUT	`/{controller}/{id}``patch(patches)`	PATCH	`/{controller}``patchById(id, patches)`	PATCH	`/{controller}/{id}``delete(id)`	DELETE	`/{controller}/{id}`---10. State Management10.1 Decision GuideState Type	SolutionLocal component state, UI flags	`signal()`Derived / computed values	`computed()`Two-way bindable state	`model()`Side effects on signal change	`effect()`HTTP / async streams, complex events	RxJS ObservablesServer data (API caching)	`@ngneat/query` via `BaseApiService`Bridge RxJS → Signals	`toSignal()` / `toObservable()`10.2 Signal Patterns```typescript// Local stateprivate readonly _isOpen = signal(false);// Computedpublic readonly buttonLabel = computed(() =>  this._isOpen() ? 'Close' : 'Open');// Effect (use sparingly)constructor() {  effect(() => console.log('isOpen changed:', this._isOpen()));}// Updatethis._isOpen.set(true);this._isOpen.update(v => !v);```---11. Testing Standards13.1 RulesFramework: Vitest (not Jasmine/Jest)All mocks go in: `shared/utility/test-mocks/` — exported via `index.ts` barrelNever use `any` in spec filesNever let tests hit APIM — always provide mock services13.2 Unit Test File Pattern```typescript// my-component.component.spec.tsimport { expect, describe, it, beforeEach } from 'vitest';import { ComponentFixture, TestBed } from '@angular/core/testing';import { NoopAnimationsModule } from '@angular/platform-browser/animations';import { MyComponent } from './my.component';import { MockMyService } from 'shared/utility/test-mocks';describe('MyComponent', () => {  let component: MyComponent;  let fixture: ComponentFixture<MyComponent>;  beforeEach(async () => {    await TestBed.configureTestingModule({      imports: [MyComponent, NoopAnimationsModule],      providers: [        { provide: MyService, useClass: MockMyService },      ],    }).compileComponents();    fixture = TestBed.createComponent(MyComponent);    component = fixture.componentInstance;    fixture.detectChanges();  });  it('should create', () => {    expect(component).toBeTruthy();  });});```13.3 npm Scripts```bashnpm run test         # Sharded Vitest runnpm run test:watch   # Watch modenpm run coverage     # Coverage reportnpm run lint         # ESLint (TS + HTML)```---14.
